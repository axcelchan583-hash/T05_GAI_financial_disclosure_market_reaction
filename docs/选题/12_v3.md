## 0. 一句话研究问题

> **中国上市公司在 GenAI 能力上的公开披露与实际投入之间是否存在系统性差距（GenAI Washing），这种差距是否预测未来兑现、资本市场反应、机构投资者行为；以及 ChatGPT 与 DeepSeek 两次冲击是否改变 washing 模式。**

这是 Barrios et al. (2025) "Artificially Intelligent or Artificially Inflated?" 框架在 GenAI 与中国场景的扩展。

---

## 1. 引言定位与四个研究问题

按 Barrios et al. (2025) 的四问结构：

1. **什么类型的公司更可能披露 GenAI 活动？**
2. **GenAI 披露是否能预测未来真实效率、创新产出、分红政策？**
3. **披露密集但实际投入不足的公司（GenAI washers）如何与其他公司不同？**
4. **GenAI 披露的资本市场后果如何？是否区分 washers 与 doers？**

这四问与 Barrios et al. (2025) 的四问完全平行，**这是有意为之**——审稿人会立即识别 framing，方法论合法性来自模仿一篇 UTD pipeline 的工作论文。

## 2. 与既有文献的差异化（核心 contribution）

| 维度 | Barrios et al. 2025 | 本研究 |
|---|---|---|
| 样本 | 美国 10,628 firm-year，2016-2023 | 中国 A 股，2022 Q4 - 2026 Q4 |
| 技术焦点 | 泛 AI（ML + AI + 一年 GenAI） | **GenAI-specific**：大模型/AIGC/智能体/RAG/Copilot/数字员工 |
| 文本 channel | 10-K + EA + CC（3） | **公告 + 年报 + 互动易 + IR（4）**——互动易是中国独有 Q&A |
| Baseline | 单源：LinkedIn AI 员工（Revelio） | **多源**：AI 招聘 + GenAI 软著 + GenAI 专利 + GenAI 产品 + CAC 备案 |
| Specificity | 5 类分类无评分 | 5 类分类 + **0-5 分 specificity score**（Hutton-Miller-Skinner 2003 _JAR_ 风格） |
| 时期 shock | 无（2023 才出现 GenAI） | **ChatGPT 2022-11 + DeepSeek 2025-01 双重 shock** |
| 主 Y | 效率 + AI 专利 + 分红 + BHAR | 效率 + GenAI 专利 + 软著 + 分红 + 长窗 CAR + 机构持股变化 + 互动易后续问答 |
| 异质性 | 治理、监督、CEO、litigation | 国企/民企、板块（主板/创业板/科创板）、互动易问答密度、shock 距离 |

**核心 contribution 句式**（在 introduction 第一段写）：

> "We extend Barrios, Campbell, Johnson, Liu (2025) and Baker et al. (2024) to study GenAI washing in Chinese listed firms. Relative to existing AI washing research, our contributions are: (1) GenAI-specific measurement, distinguishing generative AI capabilities from generic AI/ML; (2) a multi-source baseline aggregating five complementary investment channels (vs. the single LinkedIn-employee baseline in U.S. research); (3) leveraging the dual-shock design from ChatGPT (Nov 2022) and DeepSeek R1 (Jan 2025) to identify how washing patterns change with sudden technology cost reductions; (4) the first study to use China's interactive disclosure platform (互动易) as a Q&A specificity channel for capability claim verification; (5) cross-validation with China's CAC LLM registration system, a regulatory tool absent in U.S. settings."

### 3.2 假设（直接平行 Barrios H1/H2/H3a/H3b）

**H1（Barrios H1 平行版）**：GenAI 披露强度与未来真实效率、GenAI 创新产出正相关；与分红负相关。

**H2（Barrios H2 平行版）**：被分类为 GenAI washers 的公司（披露 top tercile × baseline bottom tercile）相对于非 washers，未来不展现 H1 的兑现关系。

**H3a（Barrios H3a 平行版）**：短窗市场反应在 high disclosure-high baseline、washer、low disclosure-low baseline 三组之间无显著差异。

**H3b（Barrios H3b 平行版）**：长窗 BHAR 6/9/12 月，high disclosure-high baseline 组显著跑赢其他组；washers 不仅不跑赢，反而可能跑输。

**H4（本研究独有：双 shock 假设）**：ChatGPT 节点（2022-11）触发 washing 第一波；DeepSeek 节点（2025-01）作为成本骤降冲击，washing 模式应当变化——washing 比例可能下降（兑现门槛降低），或 washing 强度上升（投资者注意力集中）。这一假设是 Barrios et al. 完全无法做的。

**H5（本研究独有：中国制度场景假设）**：在监管约束更弱、互动易问答密度低、分析师覆盖少的样本中，GenAI washing → 未兑现关系更强。

## 4. 样本与变量构造（严格平行 Barrios Section 3）

### 4.1 样本

- 中国 A 股上市公司
- 文本抓取期：2022 Q4 - 2026 Q4
- 兑现观测期：2023 Q1 - 2026 Q4
- 主分析窗：2023 Q1 - 2024 Q4 的 disclosure spike（保证 t+12-24m 在 2026 年底可观察）
- 剔除金融业（Barrios 包含金融业，但中国金融业的 GenAI 披露与其他行业差异极大，主表剔除，附录保留）

预期样本量：8,000-10,000 firm-year（与 Barrios 10,628 firm-year 同量级）

### 4.2 X：GenAI 披露（严格平行 Barrios AI_10K, AI_CC, AI_EA + 互动易扩展）

**关键词字典**（GenAI-specific，剔除泛 AI/ML）：

```
中文实体词：生成式人工智能 / 生成式 AI / AIGC / 大模型 / 多模态大模型 / 通用大模型 /
            智能体 / Agent / 知识库问答 / 检索增强生成 / RAG /
            文生文 / 文生图 / 文生视频 / 代码生成 / AI 助手 /
            Copilot / 数字员工 / 智能客服 / 大语言模型 / LLM
英文映射：generative AI / GenAI / AIGC / large language model / LLM /
          foundation model / multimodal model / AI assistant / copilot /
          agent / RAG / text-to-image / text-to-video / code generation
模型名：ChatGPT / GPT-4 / DeepSeek / 文心一言 / 通义千问 / 盘古 /
        Kimi / GLM / 百川 / 星火 / 天工
```

**剔除**：传统机器学习 / data analytics / 神经网络 / 深度学习（单独）/ 计算机视觉（除非与 GenAI 模型联用）—— 这与 Barrios 包含 ML/AI 全部词典不同，是我们 GenAI-specific 的核心。

**FinBERT 中文版本**：在 baichuan / chinese-roberta-wwm 上做 GenAI 句子分类微调。训练样本 2,000-3,000 句人工标注，目标准确率 95% 以上。

**X 测度**（直接平行 Barrios AI_CC、AI_10K、AI_EA）：

```
GenAI_公告_it = 含 GenAI 实体词 + 承诺动词的句子数 / 公告总句数
GenAI_年报_it = 含 GenAI 实体词 + 承诺动词的句子数 / 年报业务讨论部分总句数（年报 item 7 / MD&A 等同）
GenAI_互动易_it = 含 GenAI 实体词 + 承诺动词的回答数 / 互动易回答总数
GenAI_IR_it = 含 GenAI 实体词 + 承诺动词的句子数 / IR 记录总句数

GenAI_Dis_Agg_it = sum of above four
```

承诺动词字典：将 / 计划 / 正在 / 预计 / 致力于 / 即将 / 力争 / 上线 / 部署 / 接入 / 集成 / 商用 / 落地 / 推出 / 备案

**5 类 disclosure 分类**（严格平行 Barrios 5 类）：

1. General GenAI overview（"我们正在关注 GenAI 发展"）
2. Specific GenAI applications（"使用 GPT-4 改进客服"）
3. GenAI-related products / businesses / patents（"上线 AI 助手产品"）
4. GenAI capability acquisition / development（"招聘 LLM 工程师"）
5. **Forward-looking GenAI statements**（"未来三年将全面接入大模型"）

**Specificity Score（本研究独有，Hutton-Miller-Skinner 2003 _JAR_ 风格）**：

对每条 forward-looking GenAI statement 给 0-5 分：

1. 具体产品名 / 模型名 / 平台名（+1）
2. 具体业务场景（+1）
3. 具体时间表（+1）
4. 具体合作方（+1）
5. 具体业务线 / 部门（+1）

```
GenAI_FwdLooking_Specific_it = sum of (1 + score) for all forward-looking statements
```

这一变量是 Barrios 没有的，可以作为 robustness 与异质性。

### 4.3 Baseline：多源 GenAI 投入（**核心方法论差异化**）

Barrios 用单一 LinkedIn AI 员工。我们用 5 源：

```
Source 1: AISkilledHireShare_pre12m
        = AI 互补岗位招聘份额（大模型 / 算法 / 数据 / RAG / Agent / 提示工程 / AI 应用开发）
        基于第三方招聘 JD 数据

Source 2: GenAIPatentApplication_pre24m
        = GenAI 相关专利申请数（IPC G06N + 关键词联合命中）
        基于国家知识产权局

Source 3: GenAISoftwareCopyright_pre24m
        = GenAI 相关软件著作权登记数
        基于中国版权保护中心

Source 4: GenAIProductLaunch_pre24m
        = 官网 / 公众号 / 公告中可验证的 GenAI 产品或功能上线次数
        基于官网抓取 + 公告人工核验

Source 5: CAC_LLM_Registration_pre24m
        = CAC 大模型 / 算法备案登记数
        基于国家互联网信息办公室公示
```

**整合方法**：

```
PC1 = PCA 的第一主成分（标准化后）
Baseline_GenAI_Investment_it = PC1（主表）
                              = 等权 z-score 平均（稳健性）
                              = 5 个 source 各自单独（异质性 robustness）
```

**关键论证**：在 Validation 节，我们将证明任何单一 source 都无法识别完整的 baseline——单用 hiring 与 Barrios 重合但漏掉 product/registration 信息；单用 patent 漏掉服务行业；单用产品上线漏掉 B2B 公司。这是中国数据维度下 Barrios 单源做法的扩展。

### 4.4 GenAI Washing 分类（严格平行 Baker JAR + Barrios）

**主分类（Baker JAR 直接平行）**：

```
GenAI_Washer_it = 1 if firm-quarter i 在 GenAI_Dis_Agg 上 top tercile
                    AND 在 Baseline_GenAI_Investment 上 bottom tercile
                  else 0
```

**替代分类 1（Barrios alternative measure 1）**：

```
GenAI_Washer_Mvs0_it = 1 if 在 GenAI_Dis_Agg 上 top tercile AND
                            5 个 baseline source 都为 0
                       else 0
```

**替代分类 2（Barrios alternative measure 2，用 pre-period 滤掉 chronic discloser）**：

```
GenAI_Washer_pure_it = 1 if 在 2022-11 ChatGPT 前样本中
                            未出现 GenAI 高密度披露的样本中的 washer
                       else 0
```

**残差版本（本研究 robustness）**：

```
GenAITalk_it = α + β * Baseline_GenAI_Investment_it + γ * Controls_it
             + FirmFE + IndustryQuarterFE + ε_it
GenAI_Washing_Residual_it = ε_it
```

**其他分组（Barrios Section 4.5.4 平行）**：

```
GenAI_Good_it     = top tercile disclosure AND top tercile baseline
GenAI_Silent_it   = bottom tercile disclosure AND bottom tercile baseline
GenAI_Stealth_it  = bottom tercile disclosure AND top tercile baseline
GenAI_Middle_it   = middle tercile in both
```

## 5. 主要 Y 与 Capital Market Y（严格平行 Barrios Section 4.3-4.4）

### 5.1 Efficiency（直接平行 Barrios Y1）

```
Efficiency_it+1 = Stochastic Frontier Analysis (SFA)
                  Input: 营业成本、固定资产净额、研发支出净额、员工人数
                  Output: 营业收入
                  按行业-年估计
```

锚点：Aigner-Lovell-Schmidt 1977 _Journal of Econometrics_；Demerjian, Lev, McVay 2012 _Management Science_（AJG 4*）。

### 5.2 GenAI Innovation Output（差异化 Barrios Y2）

不像 Barrios 只用 USPTO AI patent ratio，我们用三 Track（中国数据更宽）：

```
GenAIPatentRatio_it+1 = GenAI 专利申请 / 总专利申请
GenAISWCRatio_it+1    = GenAI 软著登记 / 总软著登记
GenAIProductCount_it+1 = 官网新增 GenAI 产品计数
```

锚点：Babina et al. 2024 _JFE_；Giczy, Pairolero, Toole 2022（AI patent 分类标准）。

### 5.3 Dividend Payout（直接平行 Barrios Y3）

```
Dividend_it+1 = 1 if firm pays dividend in t+1
```

锚点：Barrios Section 4.3.3。

### 5.4 Capital Market Returns（直接平行 Barrios Y4 + Cohen-Malloy-Nguyen 长窗）

```
CAR_3day_iq    = 公告日 3 天累计异常收益
BHAR_6m_iq     = 6 月 buy-and-hold abnormal return（市场调整 + size-BTM 匹配组合调整）
BHAR_9m_iq     = 9 月同上
BHAR_12m_iq    = 12 月同上
BHAR_24m_iq    = 24 月（本研究独有，长窗反转）
```

### 5.5 中国独有的资本市场 Y（差异化空间）

## 6. 实证规格（严格平行 Barrios Equation 1-5）

### 6.1 Determinants of GenAI Disclosure（平行 Barrios Eq 1）

```
Y_it = α + β1 R&D_it + β2 Investment_it + β3 Age_it + β4 Size_it
     + β5 Profitability_it + β6 Tangibility_it + β7 HHI_Seg_it
     + β8 MTB_it + β9 Leverage_it + β10 N_Analyst_it
     + β11 Insti_Own_it + β12 GenAI_Dis_Ind_t,j
     + IndustryFE + YearQuarterFE + FirmFE + μ_it
```

`Y` 是 GenAI_公告 / GenAI_年报 / GenAI_互动易 / GenAI_IR / GenAI_Washer。

中国独有控制变量：国企虚拟、板块虚拟、互动易问答密度、CAC 备案数。

**Shapley decomposition**：把控制变量分四类，看 R² 贡献率：行业 / 公司 / 信息环境-外部监督 / 管理层激励。直接平行 Barrios Figure 4。

### 6.2 Disclosure → Performance（平行 Barrios Eq 2-4）

```
Y_it+1 = α + β1 GenAI_Variables_it + Γ * Controls_it
        + IndustryFE + YearQuarterFE + FirmFE + μ_it

Y_it+1 = {Efficiency, GenAIPatentRatio, GenAISWCRatio, Dividend}
GenAI_Variables = {GenAI_公告, GenAI_年报, GenAI_互动易, GenAI_IR, GenAI_Dis_Agg, AISkilledHireShare, GenAI_Washer}
```

聚类标准误：firm-level。所有连续变量在 1-99 分位 winsorize。

### 6.3 Capital Market Consequences（平行 Barrios Eq 5）

```
RETURN_iq = α + β1 High_Disclosure_Low_Baseline_iq
           + β2 High_Disclosure_High_Baseline_iq
           + β3 Ln(MV)_iq + β4 Lev_iq + β5 BTM_iq
           + IndustryFE + YearQuarterFE + μ_it

RETURN = {CAR_3day, BHAR_6m, BHAR_9m, BHAR_12m, BHAR_24m}
Reference group: Low_Disclosure_Low_Baseline
```

Robustness：bootstrap SE (1000 iter) + Fama-MacBeth + Newey-West 4 lags（直接抄 Barrios Section 4.4）。

### 6.4 双 shock 设计（本研究独有，H4 测试）

```
GenAI_Washer_it = α + β1 PostChatGPT_t + β2 PostDeepSeek_t
                + β3 PostChatGPT_t × HighGenAIExposure_i
                + β4 PostDeepSeek_t × HighGenAIExposure_i
                + Controls + FirmFE + IndustryFE + μ_it
```

`HighGenAIExposure_i` 用 Eloundou et al. 2024 _Science_ 任务暴露的中文映射 + Babina et al. 2024 _JFE_ 风格的 pre-2022 AI 基础。

预期：PostChatGPT 后 washing 飙升；PostDeepSeek 后部分公司因兑现门槛下降而退出 washing 状态（hazard model 验证）。

## 7. 稳健性与额外分析（严格平行 Barrios Section 4.5）

### 7.1 Alternative Washing Measures（Barrios Section 4.5.1）

- GenAI_Washer_Mvs0 + GenAI_Washer_pure（已在 4.4 节定义）
- 残差版本

### 7.2 ESG Falsification（Barrios Section 4.5.2）

把 Y 换成 ESG 评分 / ESG 基金流入。预期：GenAI washing 与 ESG washing 不显著相关，证明 GenAI washing 是独立现象。直接抄 Barrios Section 4.5.2 的 falsification 思想。

### 7.3 Alternative Time Periods（Barrios Section 4.5.3）

把 Y 从 t+1 扩展到 t+2、t+3。预期：washing → 不兑现关系在多年窗口都成立，排除 "washers 只是慢启动" 的可能。

### 7.4 Sample Partitions（Barrios Section 4.5.4）

按 GenAI_Good / GenAI_Silent / GenAI_Stealth / GenAI_Middle 四组分析。直接平行 Barrios Section 4.5.4。

### 7.5 Hazard Model：Washing Persistence（Barrios Section 4.5.5）

```
h(t) = λ p(λt)^(p-1) exp(β1 * R&D + β2 * Investment + β3 * Age + β4 * Size
                       + β5 * Profitability + β6 * Tangibility + β7 * HHI_Seg
                       + β8 * MTB + β9 * Leverage + β10 * N_Analyst
                       + β11 * Insti_Own + β12 * GenAI_Dis_Ind
                       + β13 * PostDeepSeek
                       + δ * IndustryFE)
```

预期：

- 中国 GenAI washing 平均持续 2-3 年（与 Barrios 美国 2.5 年同量级）
- **PostDeepSeek 显著加快退出**——这是本研究独有发现，因为 Barrios 样本没覆盖 DeepSeek

### 7.6 中国制度独有 robustness

- 剔除互动易答复，重做 X，检验 X 不依赖互动易
- 剔除 CAC 备案，重做 baseline，检验 baseline 不依赖单一 source
- 国企 vs 民企
- 主板 / 创业板 / 科创板
- 高 vs 低分析师覆盖

## 9. 主要风险与诚实声明

### 9.1 抢跑风险

Barrios et al. (2025) 与 Donelson et al. (2025 SSRN) 已经在赛道上。我们的合法定位是：

- **同期 working paper**：在 Barrios 正式发表（预计 2026-2027 投 JAR/JAE/CAR）前后挂 SSRN
- **差异化共存**：在 introduction 与 contribution 第一段就直接对比 Barrios et al. 2025，明确我们做 GenAI-specific + 中国 + 多源 baseline + 双 shock + 4 channel

不假装 "first AI washing paper"——这是不诚实的。诚实表述是 "first GenAI washing paper in Chinese setting"。

### 9.2 数据风险

- **互动易**：互动易数据由深交所维护，时间戳逐条核对工作量大。建议先抓 500 家试点，验证可行性。
- **CAC 备案**：CAC 备案覆盖只覆盖面向公众的生成式服务，B2B 内部部署不在其中。Source 5 对内部部署公司可能误判，需要稳健性排除。
- **GenAI 招聘 JD 抓取**：第三方招聘数据库的数据质量与可比性弱于 Revelio。建议主表用 PCA 整合，附录单独检验各 source。

### 9.3 时间窗口风险

- 24 月观测窗对应 t = 2024 Q4 为最后 spike，Y 测到 2026 Q4。我们正好在 2026 年中（当前），意味着主表样本只能用 t = 2022 Q4 - 2024 Q4，量级可能受限。
- 建议主表用 12 月窗，附录用 24 月窗。Barrios 用 6/9/12 月，我们顺延。

### 9.4 因果定位

本设计识别的是 GenAI 披露与未来表现的 association，而非严格 causation。这与 Barrios et al. (2025) 的因果定位一致——他们也只声明 association。审稿人攻击面较低。
