## 1. Introduction 与抢跑赛道详尽对照

### 1.1 研究问题

中国上市公司在 GenAI 能力上的公开披露与实际投入之间是否存在系统性差距，这种差距是否预测未来真实兑现、销售增长、效率提升、资本市场反应、机构投资者行为；以及 ChatGPT（2022-11-30）与 DeepSeek R1（2025-01-20）两次注意力 / 成本冲击是否改变了披露内容的形态。

### 1.4 v5 的合法 contribution 表述（写进 introduction 第一段）

> "We extend Baker et al. (2024, _JAR_) Diversity Washing framework and Chu et al. (2025, _RAS_) residual disclosure methodology to GenAI capability disclosures in Chinese listed firms. Relative to the concurrent U.S.-based literature on AI/GenAI disclosure-action gap (Barrios et al., 2025, _RAS R&R_; Jia et al., 2025, _RAS_; Li, 2025, _working paper_; Donelson et al., 2025, _working paper_; Song et al., 2026, _FRL_), our contributions are: (1) GenAI-specific measurement that distinguishes generative AI capabilities from generic AI/ML, addressing a measurement issue that all six concurrent U.S. studies aggregate; (2) a multi-source baseline aggregating five complementary investment channels (vs. the single-source Revelio LinkedIn / employee resume baseline used in all U.S. studies); (3) a multi-channel disclosure structure (formal filings + annual reports + Interactive Investor Platform + IR records) vs. the single-channel conference call or 10-K design in all U.S. studies; (4) the dual-shock design from ChatGPT (Nov 2022) and DeepSeek R1 (Jan 2025), the latter completely absent from all U.S. samples whose latest cutoff is mid-2024; (5) China's regulatory CAC LLM registration system as a cross-validation tool absent in U.S. settings; (6) China's Interactive Investor Platform (互动易) as an informal investor-interaction channel that allows us to separately measure specificity of forward-looking capability claims."

### 2.2 假设结构

**H1（Chu 2025 RAS 平行）**：在控制 baseline GenAI 能力之后，GenAI 披露的 firm-quarter 残差越大，未来 4-8 季度内销售增长越低。

**H2（Rogers-Stocken 2005 + Chu 2025 RAS 平行）**：当管理层激励倾向于过度披露时（litigation 风险低、内部人减持、财务困境、行业竞争弱），H1 关系增强。

**H3（Baker 2024 JAR 平行）**：用 within-year percentile gap 测度的 GenAI Washing Score，与未来 5 Track 兑现失败正相关。

**H4（Cohen-Malloy-Nguyen 2020 JF + Li 2025 UFL 平行）**：

- H4a：短窗 CAR(0,+1) 对 disclosure 正向，washing 残差短期不显著
- H4b：长窗 BHAR_12m / BHAR_24m 对 washing 残差显著负，对真实 walk 显著正

**H5（双 shock 话术形态漂移，本研究独有）**：

- H5a：ChatGPT 后 GenAI 披露以**基础模型能力承诺**为主（"训练自有大模型"、"开发通用 AI 平台"）
- H5b：DeepSeek R1 后因部署成本骤降，披露漂移为**应用接入承诺**（"接入 DeepSeek 改造客服"、"基于开源大模型的智能体落地"）
- H5c：DeepSeek 后高 washing 残差公司退出 washing 状态的概率上升（hazard model）

**H6（Li 2025 UFL 平行：管理层短期市场动机）**：

- H6a：在高管减持窗口前 / 后，GenAI 披露强度上升，但 baseline 不上升——平行 Li 的 CEO delta DiD
- H6b：在定增 / 配股事件窗口（中国 SEO 对应），GenAI 披露强度上升，且市场对其反应被放大——平行 Li 的 SEO event study

**H7（中国制度异质性）**：washing 残差对未来兑现的负预测在以下样本中更强：

- 监管约束弱（无问询函历史）
- 互动易问答密度低（信息环境差）
- 分析师覆盖少
- 民营企业（vs 国有）
- 创业板 / 科创板（vs 主板）

## 3. Sample and Variable Construction

### 3.1 样本

- 中国 A 股，剔除金融业（附录保留）
- 文本抓取期：2022 Q4 - 2026 Q4
- 兑现观测期：2023 Q1 - 2026 Q4
- 主分析窗：2023 Q1 - 2024 Q4 的 disclosure spike
- 预期样本量：firm-quarter level 30,000-40,000 obs（约 3,000 家公司 × 12 季度）

### 3.2 X：GenAI Capability Disclosure（4 channel）

**步骤一：GenAI 词典构造**（GenAI-specific，剔除泛 AI）

```
实体词（核心）：生成式人工智能 / 生成式 AI / AIGC / 大模型 /
                多模态大模型 / 通用大模型 / 智能体 / Agent /
                知识库问答 / 检索增强生成 / RAG /
                文生文 / 文生图 / 文生视频 / 代码生成 /
                AI 助手 / Copilot / 数字员工 / 智能客服 /
                大语言模型 / LLM
模型名：ChatGPT / GPT-4 / DeepSeek / 文心一言 / 通义千问 /
        盘古 / Kimi / GLM / 百川 / 星火 / 天工
承诺动词：将 / 计划 / 正在 / 预计 / 致力于 / 即将 / 力争 /
          上线 / 部署 / 接入 / 集成 / 商用 / 落地 / 推出 / 备案

剔除：传统 ML、data analytics、神经网络（单独）、
      计算机视觉（除非与 GenAI 模型联用）、
      工业 4.0、智能制造（除非与 GenAI 联用）
```

**步骤二：Word2Vec 动态字典扩展**（平行 Li 2025 UFL）

按 Houston, Kim, Li (2024) 与 Li 2025 UFL 的方法：每个季度训练 Word2Vec 模型（skip-gram，dim=300，window=10），动态识别与"大模型"、"AIGC"、"生成式 AI"语义最近的 100 个词。处理 GenAI 语言演化（2022-2025 期间出现的新词如 "DeepSeek"、"智能体" 等）。

**步骤三：句子级分类器**

在 chinese-roberta-wwm-ext 上微调，目标 95% 准确率。训练样本：人工标注 2,000-3,000 句（valid GenAI capability disclosure vs not）。Validation 流程参考 Bochkay et al. 2023 _CAR_。

**步骤四：4 个 channel 抓取**（按重要度排序）

```
主 channel（正式披露）:
GenAI_公告_it    = 含 GenAI 实体词 + 承诺动词的句子数 / 公告总句数
GenAI_年报_it    = 含 GenAI 实体词 + 承诺动词的句子数 / 年报 MD&A 总句数

辅助 channel（互动 / IR）:
GenAI_IR_it     = 含 GenAI 实体词 + 承诺动词的句子数 / IR 记录总句数
GenAI_互动易_it = 含 GenAI 实体词 + 承诺动词的回答数 / 互动易回答总数
                   （位置：作为 specificity / mechanism channel，不与正式披露并列；
                    ChatGPT Pro 任务六校正）

主 X 聚合：
GenAI_Disclosure_Formal_it = GenAI_公告 + GenAI_年报（主表）
GenAI_Disclosure_All_it = GenAI_公告 + GenAI_年报 + GenAI_互动易 + GenAI_IR（稳健性）
```

**步骤五：5 类 disclosure 分类**（平行 Barrios 2025）

1. General GenAI overview
2. Specific GenAI applications
3. GenAI-related products / businesses / patents
4. GenAI capability acquisition / development
5. **Forward-looking GenAI statements**（我们重点关注）

**步骤六：Specificity Score**（本研究独有，Hutton-Miller-Skinner 2003 _JAR_ 风格）

对每条 forward-looking GenAI statement 给 0-5 分（产品名 + 业务场景 + 时间表 + 合作方 + 业务线）：

```
GenAI_FwdLooking_Specific_it = sum of (1 + score) for all forward-looking statements
```

### 3.3 Baseline GenAI Capability（5 源 PCA）

```
Source 1: AISkilledHires_Level_pre12m
        = t-12m 至 t-1 期的累计 AI 互补岗位招聘水平
        关键词：大模型 / 算法 / 数据 / RAG / Agent / 提示工程 / AI 应用开发
        数据：第三方招聘 JD 数据库

Source 2: GenAIPatent_Stock_pre24m
        = t-24m 至 t-1 期累计 GenAI 专利申请存量
        识别：IPC G06N + GenAI 关键词联合命中
        数据：国家知识产权局

Source 3: GenAISoftwareCopyright_Stock_pre24m
        = t-24m 至 t-1 期 GenAI 软著存量
        识别：软著标题与摘要含 GenAI 实体词
        数据：中国版权保护中心

Source 4: GenAIProduct_Stock_pre24m
        = t-24m 至 t-1 期可验证的 GenAI 产品 / 功能存量
        数据：官网爬取 + 公告人工核验

Source 5: CAC_LLM_Registration_Stock_pre24m
        = t-24m 至 t-1 期累计 CAC 备案存量
        数据：国家互联网信息办公室公示

聚合方法：
Baseline_PC1_it = PCA 第一主成分（主表）
Baseline_Equal_it = 5 个 z-score 等权平均（稳健性 1）
Baseline_LogSum_it = log(1 + sum of 5 sources)（稳健性 2）
Baseline_SingleSource_it = 5 个 source 各自单独（异质性 robustness，每个 source 检验是否可单独识别）
```

**严格时间分离**：Baseline 用 **t-1 之前的存量水平**，Y 用 **t+1 之后的增量与销售**。X 与 Y 在变量本体上有同源风险（招聘 / 专利 / 软著 / 产品 / 备案），但在时间上严格分离。这与 Babina et al. 2024 _JFE_ 处理 AI 投资变量与未来兑现的方式一致，审稿人不会视为循环。

### 3.4 X 主测度：双轨道（v5 关键修正）

**轨道 1：Residual Disclosure**（Chu 2025 RAS 同款）

```
GenAI_Disclosure_Formal_it = α + β1 * Baseline_PC1_it
                            + β2 * R&D_it + β3 * Size_it + β4 * Age_it
                            + β5 * MTB_it + β6 * Leverage_it
                            + β7 * N_Analyst_it + β8 * Insti_Own_it
                            + β9 * GenAI_Industry_Hype_jt
                            + FirmFE + IndustryQuarterFE + ε_it

GenAI_Disclosure_Residual_it = ε_it    (主 X 测度 1)
```

**轨道 2：Within-Year Percentile Gap**（Baker 2024 JAR 同款，v5 校正：不是 tercile）

```
DisclosurePct_it = within-year percentile of GenAI_Disclosure_Formal
BaselinePct_it = within-year percentile of Baseline_PC1

GenAI_Washing_Level_it = DisclosurePct_it − BaselinePct_it    (主 X 测度 2)
GenAI_Washer_it = 1 if GenAI_Washing_Level_it > 0 else 0    (binary 版本)
```

**轨道 3（稳健性）：Cross-Fitting Residual**（ChatGPT Pro 任务六校正）

为防 baseline 模型过拟合，用 K-fold cross-fitting：

```
For each fold k:
    用 fold ≠ k 的样本估计 baseline 模型
    在 fold k 上预测 expected disclosure
    计算 fold k 的残差

GenAI_Disclosure_CFResidual_it = cross-fitted residual
```

**轨道 4（稳健性）：Li 2025 UFL 同款 Talk-Walk Gap Binary**

```
GenAI_Washing_LiStyle_it = 1 if forward-looking GenAI disclosure in q
                          AND zero new GenAI realization in q+1 to q+8
                          else 0
```

## 11. 主要风险与诚实声明

### 11.1 抢跑风险（最重要）

Li 2025 UFL working paper 与 Barrios 2025 RAS R&R 是直接威胁。我们的合法定位是：

- **同期 working paper**：在 Barrios 正式发表（预计 2026-2027）与 Li 正式发表（预计 2026-2027）之前 6-12 个月挂稿
- **差异化共存**：introduction 第一段就直接对比 6 篇 concurrent 论文，做出 6 点差异化
- 不假装 "first AI washing paper" 也不假装 "first GenAI disclosure paper"
- 诚实表述："first GenAI-specific capability claim verification in Chinese setting with multi-source baseline and dual-shock identification"

### 11.2 X-Y 同源风险（v3 遗留问题已处理）

v3 的 T1 招聘增长同时出现在 baseline 与 Y。v5 严格处理：

- Baseline：t-1 之前**存量水平**（招聘累计、专利累计、软著累计、产品累计、备案累计）
- Y：t+1 之后**增量与销售**（新招聘、新专利、新软著、新产品、新备案、未来 sales）
- 时间分离与 Babina 2024 _JFE_ 标准做法一致

### 11.3 X 测度过拟合风险（ChatGPT Pro 任务六）

Cross-fitting residual 与 multi-source baseline robustness 已应对。

### 11.4 互动易代表性

降级为 informal investor-interaction channel，主 X 不依赖互动易，已在 robustness 中检验。

### 11.5 CAC 备案覆盖局限

仅覆盖面向公众的生成式服务，B2B 内部部署不在其中。Source 5 对内部部署公司可能误判，附录有专门稳健性。

### 11.6 时间窗紧张

主样本主要落在 2023 H2 - 2024 Q4 的 disclosure spike。主表用 12m 窗，附录用 24m 窗。DeepSeek 后样本（2025 Q1 - 2026 Q4）仅供 H5 与 hazard 检验，量级偏小。

### 11.7 因果定位

本研究识别 association 而非严格 causation，与 Chu 2025 _RAS_、Barrios 2025 _RAS R&R_、Baker 2024 _JAR_、Li 2025 _UFL_ 一致。

### 11.8 DeepSeek 事件窗的春节问题

主表用 2025-02-05 春节后首个交易日。附录展示 2025-01-20 与 2025-01-27 两个 pre-春节窗。
