# v10A.1 Regulatory-Verified GenAI Adoption and Institutional Ownership Reallocation

**日期**：2026-05-17
**主 Y**：机构持股按基金 sleeve 拆分
**一句话**：用 CAC 生成式人工智能服务备案作为 verified GenAI adoption 的硬 X，检验机构投资者按基金风格 sleeve 是否系统性把仓位重新分配给验证过的 GenAI 公司。
**版本说明**：相对 v10A，本版每一步都按"前人怎么做 / 我们为什么这么做 / 文献引用"三段式重写，所有锚点限定为 AJG 3★+ 或名校 SSRN working paper。

---

## 0. 本版只回答什么

本版只回答一个问题：

> 当一家中国上市公司被网信办正式登记为面向公众提供生成式 AI 服务的主体后，不同类型的机构投资者（主动权益基金、科技主题基金、AI 主题 ETF、北向资金、被动指数基金）是否对该公司的持仓出现可识别的、按基金风格分化的重新分配？

主问题的核心结构：

```text
regulator-verified GenAI deployment
    -> active institutional reallocation toward verified adopters
    -> passive funds show null effect (placebo within Y)
```

## 0.1 理论命题

**前人怎么做的**：

披露与机构投资者关系的经典工作把机构持仓变化作为披露质量改善的资本市场后果。Bushee (1998) 提出 transient / dedicated / quasi-indexer 三分法，Bushee 和 Noe (2000) 证明披露质量与机构基础类型有系统性关系，Boone 和 White (2015) 用被动 vs 主动机构持股二分检验信息环境效应。Baker, Larcker, McClure, Saraph 和 Watts (2024) 把"talk-walk wedge → 多 intermediary 反应"做成完整范本，其中机构持仓变化是核心 Y。

AI 实证最近邻：Donelson, Kim, Kim 和 Yip (2025) 用 AI talk-walk wedge 解释科技基金与 ESG 基金的持仓分化；Boyuan Li (2025) 用机构基金持仓证明市场识别 AI washing。但**两端都是美国数据，X 都是公司自构造文本与外部行动的差距，监管者不参与验证**。

**我们为什么这么做**：

把 X 从市场验证（talk-walk gap）换成监管验证（CAC 备案），把 Y 端的 sleeve 分类从 Bushee 二分细化为 5 sleeve（含 AI 主题这个新维度），同时把被动指数基金作为 Y 包内置 placebo。这样：

- X 端不依赖公司自愿披露，回避 Jia, Li, Ma 和 Xu (2025) 与 Bertomeu, Lin, Liu 和 Ni (2025) 已经占用的"GenAI 自愿披露"赛道；
- Y 端继承 Bushee 谱系的 4★ 锚点；
- "主动应有反应、被动不应有反应"成为强可证伪假说。

## 1. 理想实验

**前人怎么做的**：

强制披露或监管认证类研究的理想实验通常表述为"对一组观察特征相似的公司，随机让其中一半被监管 X 触发，观察 Y 在 staggered 时点上的变化"。Christensen, Hail 和 Leuz (2013) 用欧盟 IFRS 强制采用作 X，Christensen, Floyd, Liu 和 Maffett (2017) 用美国矿安强制披露作 X，都借助监管者的强制性绕开公司自选择。

**我们为什么这么做**：

CAC 备案非随机但相对外生于公司当期资本市场动机——监管者按批次审核公示，公司不能自主选择公示日期。识别策略沿用 Christensen-Hail-Leuz 谱系：staggered DiD + 匹配对照组 + 报送/公示日期分离。

## 2. 分析单元

**前人怎么做的**：

机构持仓研究通常在 firm-quarter 层面分析，因为基金披露法定频率是季度（13F 在美国，机构持仓季报在中国）。Boone 和 White (2015) 与 Bushee-Noe (2000) 都是 firm-quarter 面板。

**我们为什么这么做**：

CSMAR 基金持仓数据是季频可得。Treated firm 池约 150-300 家，2022Q1-2026Q2 共 18 个季度，全样本约 4,000 家 × 18 季度。

样本筛选规则：

```text
A 股 + 港股通中国上市公司
样本期连续上市
剔除金融业（金融业 CAC 备案制度适用性不同）
剔除 ST/退市
```

## 3. 主 X：CAC 生成式 AI 服务备案

### 3.1 定义

```text
FirstCACRegistrationDate_i
    = 公司 i 或其可穿透子公司（持股 >= 50% 且经营范围覆盖该备案产品）
      首次出现在网信办「生成式人工智能服务备案」公示名单的日期

PostCAC_iq = 1[q >= QuarterOf(FirstCACRegistrationDate_i)]
EventTime_iq = q - QuarterOf(FirstCACRegistrationDate_i)
```

**前人怎么做的**：

GenAI 实证的 X 主流有三类：(a) 文本自愿披露强度 — Jia, Li, Ma 和 Xu (2025) 用业绩电话会 GenAI 提及；(b) 外生技术冲击 — Eisfeldt, Schubert 和 Zhang (2023) 用 ChatGPT 发布日；(c) AI 人力资本 — Babina, Fedyk, He 和 Hodson (2024) 用 LinkedIn 简历构造 firm-level AI investment。强制监管登记作 X，在 AJG 4★+ 文献的 IFRS / Reg FD / 矿安披露中很常见 (Christensen 系列)，但**在 GenAI 文献中尚无先例**。

**我们为什么这么做**：

CAC 备案是中国 2023 年 8 月《生成式人工智能服务管理暂行办法》强制要求的登记，覆盖向公众提供 GenAI 服务的全部主体，截至 2025 年底累计 ~748 个备案服务 + ~435 个登记应用，分布在 10-12 个 staggered 批次。相对上述三类 X：

- 比 (a) 硬——监管者审核，不是公司话术；
- 比 (b) 细——是公司层、有公司主体的时点，不是市场层共时冲击；
- 比 (c) 窄——只算面向公众的 GenAI 服务，不算泛 AI 人力资本。

把 CAC 备案当 X 是 Christensen 系列方法学传统向 GenAI 场景的移植。

### 3.2 报送日期与公示日期分离

```text
ReportingDate_i  = 公司向 CAC 提交备案申请的日期（如可得）
PublicDate_i     = CAC 公开发布备案名单的批次日期
```

主表用 PublicDate_i。

**前人怎么做的**：

事件研究文献区分"决策日"与"公开日"是标准做法。Hutton, Miller 和 Skinner (2003) 在管理层预测可信度研究中明确区分预测日期与披露日期，以隔离信息可得时点。

**我们为什么这么做**：

机构投资者在公示之前不可知公司是否被验证。PublicDate_i 是 CAC 按批次审核完毕后统一发布，相对公司而言外生。

**文献引用**：

| Eisfeldt, A. L., Schubert, G., & Zhang, M. B. (2023). Generative AI and firm values. NBER Working Paper, UCLA Anderson WP. | NBER WP | — | GenAI 外生冲击 X 先例 |

### 3.3 X 测的是什么

明确把 treatment 框成 **public-facing GenAI deployment**，不是 GenAI usage。监管者关心的、机构投资者关心的、市场关心的也都是面向公众的可销售产品。

## 4. 主 Y 与 Y 包

### 4.1 主 Y：机构持股按 sleeve 拆分

```text
Y1a = Δ ActiveEquityFundHoldings_iq    主动权益基金持股比例季度变化
Y1b = Δ TechThemedFundHoldings_iq      科技主题基金持股比例季度变化
Y1c = Δ AIThemedETFHoldings_iq          AI 主题 ETF 持股比例季度变化
Y1d = Δ NorthboundHoldings_iq           沪深港通北向持股比例季度变化
Y1e = Δ PassiveIndexFundHoldings_iq    被动指数基金持股比例季度变化（Y 内 placebo）
```

预期：

```text
Y1a, Y1b, Y1c, Y1d > 0 after PostCAC
Y1e ≈ 0 after PostCAC
```

**前人怎么做的**：

机构投资者类型分化研究有清晰谱系。Bushee (1998) 提出 transient / dedicated / quasi-indexer 三分；Bushee 和 Noe (2000) 进一步证明披露质量改善会吸引特定类型机构；Boone 和 White (2015) 区分被动 vs 主动机构持仓在信息生产中的差异化作用；Edmans, Fang 和 Lewellen (2017) 探讨机构持仓与公司投资决策。AI 直接近邻方面，Donelson et al. (2025) 与 Boyuan Li (2025) 都使用了按基金风格 sleeve 拆分（科技基金、ESG 基金、AI 主题基金）作 Y，但是美国数据。

**我们为什么这么做**：

(1) 多主体聚合——每个 sleeve 背后是几十到几百个独立基金决策；(2) Y 内置 placebo——被动指数基金按指数权重调仓，CAC 备案不应改变其持股，主动应该改变；(3) 方法学锚定在 Bushee 谱系，4★ 直接支撑；(4) AI 维度细化（加入 AI 主题 ETF 与北向）反映 2023-2026 中国资本市场新结构。

### 4.2 基金 sleeve 分类的执行口径

数据源：CSMAR 基金持仓表（季频）+ 基金分类信息 + Wind 北向资金数据。

```text
ActiveEquity:
    投资类型 = 偏股混合 / 灵活配置 / 普通股票
    且非指数型
    且基金名称不含「指数」「ETF」

TechThemed:
    基金名称或类型含「科技」「TMT」「信息」「软件」「电子」「半导体」「计算机」
    且主动管理

AIThemed:
    基金名称或代码含「人工智能」「AI」「智能」「大模型」「GAI」「AIGC」
    含 ETF 与主动基金，单独列

Northbound:
    沪股通 + 深股通 累计净持股（Wind / CSMAR 直接下载）

PassiveIndex:
    基金类型 = 被动指数型 / ETF
    且基金名称不含「人工智能」「AI」（剔除 AI 主题 ETF 避免重复）
```

基金分类规则在 Appendix 完整披露。每个 sleeve 给出"基金数量、净资产合计、持 A 股市值合计"。

**前人怎么做的**：

Bushee (1998, 2001) 用三分法时给出明确机构分类规则；Boone 和 White (2015) 给出准被动 vs 主动的细分规则；Donelson et al. (2025) 用 CRSP/Lipper 给出科技 vs ESG 基金的命名匹配规则。

**我们为什么这么做**：

中文基金市场分类规则不能照搬美国，采用 Donelson 命名匹配 + Bushee 持仓行为双重过滤的方法。

## 5. X/Y 隔离规则

**前人怎么做的**：

事件研究与 DiD 文献要求 X 测度区间与 Y 测度区间时间不重叠，否则 X 和 Y 同源带来机械相关 (MacKinlay 1997 review)。

**我们为什么这么做**：

```text
X 测度区间：q <= QuarterOf(PublicDate_i)
Y 测度区间：q > QuarterOf(PublicDate_i)
```

X 是监管者公示，Y 是机构投资者持仓——决策主体完全不重叠，X/Y 同源问题不存在。

## 6. 识别策略

### 6.1 主估计量：Callaway-Sant'Anna staggered DiD

**前人怎么做的**：

近年顶刊 DiD 文献揭示 TWFE 在 staggered 处理下产生 "forbidden comparisons" 偏误。Goodman-Bacon (2021) 把 TWFE 分解为已处理与已结束处理组的加权平均；Sun 和 Abraham (2021) 给出 interaction-weighted estimator；de Chaisemartin 和 D'Haultfœuille (2020) 与 Borusyak, Jaravel 和 Spiess (2024) 提出更稳健的 imputation estimator；Callaway 和 Sant'Anna (2021) 提出 group-time ATT 估计量配合 not-yet-treated 对照组，是当前会计/金融 4★ 期刊中 staggered DiD 的默认估计量。

**我们为什么这么做**：

CAC 公示 10-12 批次是 staggered treatment 的典型情形。Callaway-Sant'Anna 的 group-time ATT(g, t) 配合 not-yet-treated 对照组，避开 TWFE 偏误，且配合 doubly robust IPW-OR 加权可控制协变量。

```text
ATT(g, t) = E[Y_{i,t}(g) - Y_{i,t}(∞) | G_i = g]
ATT(e) = sum_g w_g * ATT(g, g+e)
```

### 6.2 推断：cluster + jackknife

**前人怎么做的**：

Petersen (2009) 论证面板数据双向 cluster 标准误；MacKinnon, Nielsen 和 Webb (2023) 在 *Journal of Econometrics* 综述 cluster robust inference 的最新发展；近年文献开始用 wild cluster bootstrap 与 jackknife inference 应对小 cluster 数。

**我们为什么这么做**：

主表 cluster by firm；稳健性叠加 wild cluster bootstrap 与 cluster jackknife。CAC 批次内公司在时间上聚集，cluster jackknife 是更稳的推断。

### 6.3 Event-study 形式

```text
Y_iq = sum_{e=-4, e!=-1}^{8} beta_e * 1[EventTime_iq = e]
        + alpha_i + delta_{j(i)q} + X_iq * gamma + eps_iq
```

参照组 e = -1。

约束：

- 主表 K_pre = 4，K_post = 8 季度
- pre-trend：β_{-4}, β_{-3}, β_{-2} 应接近 0
- post 关注：β_0 到 β_8

**前人怎么做的**：

event-study 设计是 Jacobson, LaLonde 和 Sullivan (1993) 早期范本，近年由 Borusyak et al. (2024) 与 Sun-Abraham (2021) 重新规范。

**我们为什么这么做**：

```text
treated firm 池内基金持仓覆盖 >= 95%
```

```text
Y1a β_{-4} 到 β_{-2} 是否 ≈ 0
```

Go/no-go：

```text
pre-trend joint F-test p-value > 0.20
Y1a β_0 或 β_1 显著正
Y1e 全不显著
```
