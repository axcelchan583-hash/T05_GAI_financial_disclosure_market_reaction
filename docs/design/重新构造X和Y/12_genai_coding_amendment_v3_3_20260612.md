# T05 GenAI 公告编码增补 v3.3：compute 供应链组件与少数股权收购边界（20260612）

本增补在 v3.1 判定树与 v3.2 GenAI value-chain 口径之上，只修正两个已在人工复核中暴露的边界。编码时以 `08 + 10 + 12` 为准。

## 1. 光模块 / 光芯片：进入 compute 的专用性 gate

光模块、光芯片、光互联等确实可能是 AI 算力供应链的一部分，但不能自动进入 `L=compute`。否则普通通信设备、5G、数据通信和泛数据中心公告会被系统性误收。

### 1.1 进入链内的条件

若公告的产出、标的或交付物明确服务以下对象，可判为链内：

- AI 算力集群、智算中心、AI 数据中心；
- 大模型训练 / 推理、高性能 GPU 服务器互联；
- 800G / 1.6T、硅光、CPO 等明确用于 AI 算力基础设施的高速互联产品；
- 标的公司主要业务明确为服务 AI 算力或大模型基础设施。

人工码：

```text
A 或 D-fw | L=compute
```

A / D-fw 仍由可信性决定：承诺真实且首次为 `A`；只有框架/意向/无实质承诺为 `D-fw`。

### 1.2 不进入链内的条件

若只是以下情形，不能因"AI 需求"或"AIGC 带动行业景气"而判链内：

- 普通通信光模块、光通信器件、5G、数据通信产品；
- GenAI 只出现在行业背景、投资目的、风险提示或市场空间描述；
- 公告方自己的产出/标的/交付物未明确服务 AI 算力基础设施；
- 仅称"下游客户包括数据中心"但没有 AI 算力或大模型专用性证据。

人工码：

```text
D
```

若文本暗示 AI 数据中心用途但证据不足，判：

```text
U | 备注=光模块/光芯片 AI算力专用性不足，需人工查全文或外部资料
```

## 2. 控股子公司少数股东权益收购：默认 C

上市公司收购已经控股的 AIGC / 大模型子公司少数股东权益，通常只是权益比例调整、内部股权整理或利润归属变化，不是新的 GenAI initiative。

默认规则：

```text
C
```

适用情形：

- 公告写明"控股子公司"、"收购少数股东权益"、"进一步提升持股比例"；
- 文本显示公司此前已收购、设立或披露该 GenAI 子公司 / 标的；
- 本次交易没有新增 GenAI 项目、上线、投资建设、取得控制权或新的链内业务承诺。

人工码示例：

```text
人工码: C | 证=公司此前已收购该AIGC子公司控股权，本次为收购少数股东权益、进一步提升持股比例
```

### 2.1 例外：可以不是 C 的情况

以下情况不要机械判 C：

1. **首次披露但日期不一定可用**：本公告第一次让市场知道该子公司有明确 GenAI 链内业务，但业务显然早已存在。优先判 `B` 或 `U`，并回查更早首次日期。
2. **取得控制权**：此前只是参股或合作，本次交易取得控制权且标的明确链内，按投资/收购 gate 判断，可能为 `A | M=ext`。
3. **新增实质 GenAI 承诺**：少数股权收购同时披露新的大模型、AIGC 产品上线、智算中心建设、明确新增投资等，且公告日可用，可能为 `A`。

## 3. 上海电影校准判例

`601595 上海电影` 2024-11-23《收购控股子公司少数股东权益暨关联交易的公告》应判 `C`：

- 2024 公告自身写明"自公司 2023 年收购上影元 51%股权以来"、"本轮少数股权收购，进一步提升持股比例"；
- 2023-06-03 公告已经披露合资公司"以领先的AI技术能力和丰富的内容储备，加速接入AIGC赛道"；
- 因此 2024-11-23 不是首次 GenAI initiative。

人工码：

```text
人工码: C | 证=公司2023年已收购上影元51%股权且2023年6月公告已披露接入AIGC赛道；本次为收购控股子公司少数股东权益、进一步提升持股比例
```

## 4. 对全量 LLM 预编码的要求

全量 DeepSeek 预编码必须显式包含本增补规则。模型输出中：

- 光模块/光芯片若判 `A` 或 `D-fw`，`reason` 必须说明 AI 算力专用性证据；
- 控股子公司少数股东权益收购若判 `A`，`reason` 必须说明为何不是既有 GenAI 布局的后续权益整理；
- 以上两类若证据不足，`review_priority` 必须为 `must_review`。
