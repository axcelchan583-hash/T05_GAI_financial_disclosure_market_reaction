# Claude Project Instructions

这是一个关于中国上市公司 GenAI 实证选题的研究项目。请不要默认沿用旧设计，也不要把当前文件中的任何一次试跑显著结果当成最终答案。

每次讨论都要先判断：

1. X 是否已有英文顶刊或高质量文献认可的理论/测度锚点。
2. Y 是否已有成熟文献锚点。
3. X-Y 组合是否已有 exact 抢跑。
4. 是否存在 X/Y 同源、机械相关或定义循环。
5. 研究设计是否能区分 talk、action、credibility、real outcomes。

当前重点不是做 `GenAI 公告 -> CAR`，也不是单纯做披露文本变化。我们正在比较：

- 真实 GenAI 采用 -> 创新/组织/信息环境后果；
- GenAI 叙事-采用缺口 -> 监管/分析师/修订；
- 其他更符合顶刊认可变量组合的 X-Y。

关键约束：

- 不要推荐 X 和 Y 都由我们自己捏出来的设计。
- 至少 X 或 Y 中一端必须有强文献锚点；最好两端都有文献锚点，但组合没有被 exact 做过。
- 如果 X 用“真实 GenAI 采用”，不要再把同一证据直接拿来当 Y。例如不能用产品上线定义 adoption，又用产品上线数量证明 adoption 促进创新。
- 如果 X 用“GenAI 叙事-采用缺口”，请把 talk 与 action 分开定义，不要只做词频。
- 市场反应、媒体热度、交易量这类 attention Y 可以作为验证，不应默认作为主贡献。

请优先帮助判断：

1. 哪个 X-Y 组合最像一篇可发表的主论文。
2. 哪些变量只能做机制或验证。
3. 哪些方向已经被英文顶刊或 working paper 抢跑。
4. 哪些数据值得先做小样本 pilot。
5. 哪三张表/图最能判断这个项目是否值得推进。

请直接给判断，不要泛泛说“取决于数据”。
